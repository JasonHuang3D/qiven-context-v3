# erp

layer products, status slot

- **Will hold:** an enterprise AI-based ERP
- **Never holds:** another product's code
- **Contract a filler meets:** its own name for namespace, targets, macros and include root; a contract of its own only in its modules' public headers; its program (`app`) alone chooses the adapters; its whole-program tests beside its program
- **May depend on:** core, system, services, kits
- **Parameters:** none
- **Filling it:** its modules, each a directory with module.json and README.md, its targets and tests under its own name, status set to `built`; no other module changes
