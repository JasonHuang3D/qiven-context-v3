# qiven3

layer products, status group

The cognition product: its format's names, the entry, the secret check, `checked`, `write`, location,
its program and its whole-program tests. Its code keeps the name `qiven3`: namespace, targets, macros.

- The products layer's edges: depends on the foundation and the kits. An edge goes down only; within a layer a module depends on another only by a declared edge; the graph has no cycle.

Each subdirectory holding a module.json is one module or slot; its README.md is its charter.
