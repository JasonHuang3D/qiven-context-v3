# The Linux toolchain of the local loop, on WSL2's Ubuntu 24.04 LTS: one pin
# a line, KIND NAME VERSION SHA256 SOURCE, which tools/linux_pins.py checks
# against the installed tools (see its text for each kind). A prefix/ source
# is under the install prefix the check is given; path/ is found on PATH.
# A trailing comment says where a digest comes from: published (the
# release's own digest list), github-asset-digest (the release asset's digest
# as GitHub gives it), observed (taken from the file here; for a download,
# one whose release publishes no digest, or none of SHA-256, checked as the
# comment says).
# The compilers are under the prefix: clang, clang++ and llvm-symbolizer
# from LLVM's release archive (llvm), by GitHub's asset digest; GCC built
# under the prefix from gnu.org's release source (gcc-source), checked by
# its published SHA-512 and its signature, with its prerequisites (gmp,
# mpfr, mpc, isl, gettext) by GCC's own list of their SHA-512s, built in
# GCC's tree; each by its versioned name in the prefix's bin/.
# libcxx-msan is libc++ with libc++abi within it, built from llvm-source
# under MemorySanitizer with origins as msan.yml builds it; the linux-msan
# preset reads its prefix from QIVEN3_LIBCXX.
# Each deb's digest is the archive index's, checked on the downloaded .deb
# before it was installed, with no recommended package: make (CPython's
# build), m4 and bzip2 (GCC's build), glibc's development files, and the
# compilers before those under the prefix, gcc-14, g++-14, clang-18,
# libclang-rt-18-dev and llvm-18, with their dependencies, which the loop no
# longer runs and which stay until their removal.
# Their hold: the deb pins of the source packages gcc-14 and
# llvm-toolchain-18 are held (apt-mark hold) until then, and no other
# package is, so that the system's updates stay on; tools/linux_pins.py
# checks it.
