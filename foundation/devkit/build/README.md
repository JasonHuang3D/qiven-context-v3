- **Holds:** `build.cmake` (`qiven_root`, the checkout's root, from which every repository path of the foundation's CMake starts; the options, pins, compiler flags, hardening, sanitizers, clean binaries, analysis and `qiven_executable`), `top.cmake` (what the project on top holds, by the same parts in whichever project: the trees, the tidy configuration, the codemodel query, `enable_testing` and the header units' rule at its one include, and `qiven_top_end()`, called last: the foundation's pair of header units for the analysis, `qiven_headers` and `qiven_test_headers`, `binaries.txt`, `executables.txt`, `test-targets.txt`, `defined-targets.txt` and the clang-tidy steps), `modules.cmake` (the one list of the foundation's modules, `qiven_foundation_modules`, each added there, at the top project's scope), `sanitize.cmake`, `tidy_database.cmake`, `trees.cmake` (the trees of `tools/trees.json`, the globs and filters taken from them, and `qiven_kept`, the one filter, narrowing the walks to the `qiven_kept_tree` a project on top names, the table read whole), `header_units.cmake` (the header units, their places and names, and the function that makes a pair of them, which `trees.cmake` includes), `tidy_config.cmake` (a test source's composed clang-tidy configuration), the rule sets `analysis.ruleset` and `stack.ruleset`, the analysis exemptions `analysis-exemptions.json` and the test configuration over them (`analysis-test.ruleset`, `analysis-test.clang-tidy`); its own Python tests (`tests/`: the trees' globs and filters, `test_trees_build.py`, every executable made by `qiven_executable`, `test_executables.py`, and the standard library's hardened mode, `test_hardened.py`); at the root, `CMakeLists.txt` (the composition: `build.cmake`, `top.cmake`, `modules.cmake`, the product's directories, `qiven_top_end()`), `CMakePresets.json` (the sanitizer and analysis presets, which includes `foundation/CMakePresets.json`) and `.clang-tidy`; in `foundation/`, `CMakeLists.txt` (the foundation alone, the project with no product directory, by the same parts: its `qiven_kept_tree`, and `qiven_left_out`, the Python tests it leaves out of the listing, each named with its reason) and `CMakePresets.json` (the presets' common part, `base`, `here`, `ci` and the test preset `here`; and `alone`, configure and test, disabled at the root, its tree `build/alone` under the root)
